# MacPulse 0.9.1

## What's new

- **Uninstaller Pro:** sort applications by size, name or last use; filter unused apps (over three months) and unsigned apps. Spotlight dates include a labelled modification-date fallback.
- **Code signatures:** local Security framework checks distinguish Apple / Developer ID, self-signed / Ad-Hoc, unsigned, invalid and unavailable signatures. This does not assert Apple notarization.
- **Update checks:** Settings can check GitHub for a newer stable release, show its date and release notes, and open the DMG download in your browser.
- **Personalization:** six accent colors with immediate, persistent application across the interface; all new messages are available in 12 languages.
- **Stability and diagnostics:** responsive login-item changes, Dock/menu-bar modes, smoother history charts, CPU test telemetry and cancellation, a display-test HUD, traceroute, IPv6 checks and configurable public-IP history.

## Installation

Download `MacPulse.dmg`, open it and drag MacPulse into Applications, replacing the previous version after quitting it. Requires macOS 13 or later; the DMG includes Intel and Apple Silicon binaries. The build is ad-hoc signed, not Developer ID notarized. Existing settings are retained.

## Verification and limits

102 test cases: 96 regular checks pass; six hardware/network tests are opt-in. Both CPU architectures are compiled, with runtime checks on Intel Sonoma. Apple Silicon and Ventura runtime verification still require those machines. Sensor availability depends on hardware. Apple Silicon fan control remains read-only. CPU frequency is nominal when live frequency is unavailable; performance is relative to the best measured run on that Mac.

## Что нового

- Деинсталлятор: размер, дата последнего использования, сортировка и фильтры. Если Spotlight не отдаёт дату, используется явно отмеченная дата модификации.
- Проверка цифровых подписей приложений, включая повреждённые и отсутствующие подписи. Проверка подписи не подтверждает нотарификацию Apple.
- Проверка обновлений в Настройках, описание изменений и кнопка скачивания DMG.
- Шесть акцентных цветов и локализация новых элементов на 12 языках.
- Исправления автозапуска, Dock/Cmd+Tab и графиков; улучшенные CPU-тесты, экранный HUD и сетевая лаборатория.

Для установки завершите MacPulse и замените приложение в папке «Программы» версией из DMG. Настройки сохраняются. Требуется macOS 13+; Universal для Intel и Apple Silicon. Сборка пока без нотарификации Apple.
