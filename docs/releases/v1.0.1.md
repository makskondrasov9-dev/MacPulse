# MacPulse 1.0.1 — Independent widgets, consistent colors and smoother monitoring

A focused update to the native macOS system suite: redesigned desktop panels, reliable menu-bar rendering, clearer Settings and less unnecessary background work.

## Desktop widgets: choose exactly what you need

Enable **CPU & GPU**, **Memory & Storage**, **Network** or the optional **System Summary** independently in Settings → Widgets. Disabling a panel preserves the other windows. The master switch pauses/resumes the selected group.

| Widget | Small · 160×160 | Medium · 340×160 | Large · 340×340 |
|---|---|---|---|
| CPU & GPU | Two percentage rings | CPU/GPU sparklines and percentages | Minute-long load histories, available chip temperatures, nominal CPU clock and throttling information |
| Memory & Storage | RAM/SSD rings with used/total amounts | Exact used/total amounts and bars | Active/wired/compressed/free memory breakdown, storage usage and available SMART/life/TBW |
| Network | Compact speed gauge | Current download/upload and activity | Separate incoming/outgoing histories, local/public IP and session totals |
| System Summary | — | CPU, GPU, RAM, disk and network | Combined metrics with load histories |

Size controls now work in the right-click menu and Settings. Resizing preserves the top-left corner. Movement locks, saved positions, desktop/always-on-top modes, 40–100% opacity and click-through remain available.

## Menu bar and Settings

- Fixed disappearing colored text beside sparklines by rendering the complete status label as one composition.
- **Accent:** both charts use the selected accent. **Category:** cyan CPU, green network. **Dynamic:** green/orange/red by CPU load and relative network activity. **Monochrome:** system foreground.
- Four Settings tabs: **General**, **Menu Bar**, **Widgets**, **Network & IP**.
- Static dashboard card rows and native scroll-position restoration prevent jumps when hiding unavailable values or returning from Settings.

## Performance and verification

- Menu-only monitoring samples selected services every three seconds. Visible windows, popovers and enabled panels use the configured interval.
- Widget requirements are combined with selected menu metrics; a network-only panel does not request unused RAM/GPU/SMC/storage services. Active fan-control heartbeats retain their fast safety cycle.
- Shared widget history is capped at 20 buckets over a minute; formatters and status images are cached.
- **116 regular tests passed; six hardware/network opt-ins skipped.** Native checks cover all **11 supported layouts**, independent selection, retained windows, resize anchoring, palette rendering and scroll restoration.
- Both app and fan helper contain **x86_64 + arm64**, targeting **macOS 13 Ventura or later**. All **494 messages across 12 languages** validated.
- Menu-only CPU samples on the Intel iMac were approximately **0.28–0.30% of one core** with panels closed. This is a measured configuration, not a universal CPU ceiling. [Method and limits](https://github.com/makskondrasov9-dev/MacPulse/blob/v1.0.1/docs/PERFORMANCE.md).

## Install or update

1. Quit the running MacPulse.
2. Download **MacPulse.dmg**, open it and drag MacPulse into **Applications**, replacing the previous copy. Preferences are retained.
3. Open MacPulse. Configure the panels in **Settings → Widgets**.

Project-maintained Homebrew tap:

```sh
brew tap makskondrasov9-dev/macpulse https://github.com/makskondrasov9-dev/MacPulse.git
brew install --cask makskondrasov9-dev/macpulse/macpulse
```

For an existing Homebrew installation: `brew update` then `brew upgrade --cask makskondrasov9-dev/macpulse/macpulse`.

Build **18**. The app is ad-hoc signed, without Developer ID signing or Apple notarization. If macOS blocks first launch, follow the [installation instructions](https://github.com/makskondrasov9-dev/MacPulse#gatekeeper--first-launch). `SHA256SUMS` is attached for verification.

Hardware readings remain capability-dependent. CPU frequency is explicitly nominal; unsupported temperatures/power limits/SMART remain unavailable. Public IP requires enabling its configured lookup. Dynamic network color reflects recent activity, not measured link saturation. Apple Silicon fan control remains read-only. Monitoring, cleanup, uninstaller, diagnostics, network processes and opt-in usage insights are retained.

## MacPulse 1.0.1 — что нового

### Независимые виджеты

В «Настройки → Виджеты» отдельно включаются **CPU/GPU**, **Память/Диск**, **Сеть** и **Сводка системы**. Общий выключатель приостанавливает выбранную группу; отключение одной панели сохраняет остальные окна и координаты.

- **CPU/GPU:** два кольца в Small, спарклайны в Medium, минутная история, температуры, номинальная частота CPU и сведения об ограничении производительности в Large.
- **Память/Диск:** кольца с объёмами, точные показатели RAM/SSD и подробная разбивка памяти с доступными SMART, ресурсом SSD и TBW.
- **Сеть:** компактный спидометр, скорости и график активности; в Large — отдельные графики приёма/отдачи, IP и трафик сессии.
- **Сводка:** отдельная смешанная панель только в Medium/Large.

Исправлены неактивные пункты размера в контекстном меню. Изменение размера сохраняет верхний левый угол; размер и закрепление также доступны в Настройках.

### Интерфейс и оптимизация

- Цветной текст больше не исчезает рядом с графиками меню-бара. Оба графика следуют общей схеме: акцент, категории, динамическая окраска или монохром.
- Четыре вкладки Настроек: «Основные», «Строка меню», «Виджеты», «Сеть и IP».
- Прокрутка Монитора сохраняется при скрытии недоступных карточек и переходах между разделами.
- В фоне опрашиваются выбранные показатели, история ограничена, лишние форматирования и перерисовки сокращены. Быстрый цикл активного управления вентиляторами сохранён.

**Проверено:** 116 обычных тестов успешно выполнены, 6 аппаратных/сетевых проверок включаются отдельно; проверены 11 компоновок виджетов и все схемы цветов. Universal Intel/arm64, macOS 13+, 12 языков, сборка 18.

Для обновления завершите MacPulse и замените приложение в «Программах» копией из DMG. Настройки сохраняются. Публичный IP отображается после включения запроса в «Сеть и IP»; доступность датчиков и SMART зависит от оборудования. Сборка пока не нотарифицирована Apple.
