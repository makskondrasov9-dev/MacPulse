# MacPulse 1.0.0 — Desktop, network and usage insights

MacPulse brings its monitoring, cleanup, fan tools and diagnostics together with three new capabilities:

- **Floating desktop HUDs:** CPU/GPU sparklines, RAM/disk gauges and live network speed. Drag panels anywhere, restore positions on launch, choose desktop or always-on-top level, set 40–100% opacity or enable click-through.
- **Process network activity:** visible TCP/UDP sockets with process names, icons, PIDs, local/remote endpoints and connection state. Search by name or port; switch between active remote connections and all visible sockets. Queries run only while the Network section is open.
- **Screen Time Lite and peaks:** optional local top-five foreground-app time with colored bars, event-driven app switching, and CPU peak temperature with timestamp alongside RAM/GPU records.

Also includes the 0.9.1 improvements: app signature metadata and sorting, update checks, accent colors, login-item responsiveness and the expanded diagnostics lab.

## Install

Quit MacPulse, open `MacPulse.dmg`, and drag the app into Applications. Existing settings remain. Requires macOS 13 Ventura or later. Universal x86_64 + arm64; build 17. The app is ad-hoc signed, not Apple notarized.

## Privacy and hardware support

Usage tracking is opt-in and stored locally. No window titles or document names are collected. Process connections are limited by macOS permissions; no elevated helper or DNS lookup is used. A socket does not prove traffic is currently flowing. Hardware sensors remain model-dependent, and Apple Silicon fan control is read-only.

## MacPulse 1.0.0 — что нового

- Три виджета на рабочем столе: CPU/GPU, RAM/диск и сеть. Перетаскивание, запоминание координат, прозрачность 40–100%, режим поверх окон или над обоями, пропуск кликов.
- Новая вкладка «Сеть»: TCP/UDP-соединения процессов с PID, иконками, адресами, портами и состоянием. Поиск и фильтр активных удалённых соединений; опрос прекращается при закрытии раздела.
- Топ-5 программ по времени использования с цветными шкалами. Учёт включается пользователем и хранится локально. Температурный рекорд CPU показывает время достижения пика.
- Сохранены диагностика железа и сети, клинер, деинсталлятор, настройки меню-бара и все возможности 0.9.1.

Для установки завершите MacPulse и замените приложение в «Программах» версией из DMG. Минимальная система macOS 13; один установщик для Intel и Apple Silicon. Сборка пока не нотарифицирована Apple.
